# StyleNest 🛍️

**StyleNest** is a modern and simple clothing store website created as a web development project.

The project focuses on creating a clean shopping experience with product browsing, a catalog, individual product pages, and a shopping cart.

## ✨ Features

* 🏠 Modern landing page
* 👕 Clothing and footwear sections
* 🛍️ Product catalog
* 🔎 Product search
* 📦 Individual product pages
* 🛒 Shopping cart
* 📱 Responsive layout
* 🎨 Custom UI design and styling
* ⚡ Interactive elements powered by JavaScript

## 🛠️ Technologies

* **HTML5** — page structure
* **CSS3** — styling and responsive design
* **JavaScript** — interactivity and dynamic functionality
* **Google Fonts** — typography
* **Modern Normalize** — consistent browser styling

## 🚀 Getting Started

No installation or additional dependencies are required.

1. Clone the repository:

```bash
git clone https://github.com/AlexAvilov345/ReleaseProject.git
```

2. Open the project folder.

3. Launch `index.html` in your browser.

That's it — the website is ready to use.

## 🎯 Project Goal

The main goal of StyleNest is to practice front-end web development and create a complete e-commerce interface from scratch.

The project combines multiple pages, custom styling, product presentation, and JavaScript functionality into one website.
